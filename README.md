# Player_Retention_Analysis_Riftbound
Analysis of new-player conversion and retention for a trading card game using Python, SQL, Excel, and PowerPoint.

## Project overview

This project examines the fictional journey of new Riftbound players from
initial interest through first purchase, organized-play participation, and
repeat event attendance.

The goal is to identify which acquisition channels, entry products, and
first-event experiences are associated with stronger player conversion and
retention.

## Business question

How can Riftbound convert more interested consumers into active players and
retain those players through organized play?

## Player journey

1. A potential player signs up or expresses interest.
2. The player purchases their first Riftbound product.
3. The player attends their first organized-play event.
4. The player returns for another event.
5. The player continues participating within 30, 60, or 90 days.

## Planned tools

- Python for data generation, cleaning, and analysis
- SQL for database queries
- Excel for the insights dashboard
- PowerPoint for the executive presentation
- AI for structured narrative assistance
